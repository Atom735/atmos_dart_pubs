# Third-party color themes

Color theme JSON under this directory is copied from **VS Code** and **Cursor**
built-in extensions for use as samples / bundled assets.

## VS Code (`defaults/`, `abyss/`, `kimbie-dark/`, `monokai/`, …)

Source: [microsoft/vscode](https://github.com/microsoft/vscode) extensions
(`theme-defaults`, `theme-abyss`, `theme-monokai`, …).

License: MIT (Copyright (c) Microsoft Corporation).

`2026-dark.json` / `2026-light.json` were taken from `main` of that repo;
other defaults and named themes were copied from a local Cursor install
(which vendors the same VS Code theme extensions).

## Cursor (`cursor/`)

Source: Cursor application `extensions/theme-cursor`.

These files are Cursor product themes. Redistribute according to Cursor’s
terms for the installation you copied them from; they are included here as
development / demo assets for parsing and UI previews.
