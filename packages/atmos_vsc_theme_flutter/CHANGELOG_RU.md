# Changelog

English: [CHANGELOG.md](CHANGELOG.md).

## 0.3.0

- `VscThemeAssetLoader` — загрузка bundled-тем из `AssetBundle` с `include`
- Ассеты всех папок тем `atmos_vsc_theme` в `flutter: assets:`
- Nullable `VscColor?.toFlutterColor()`

## 0.2.0

- `VscThemeScope` / `context.vscTheme` для темы в поддереве
- Зависимость от типизированных `theme.colors.*` в `atmos_vsc_theme`

## 0.1.0

- Первый релиз пакета `atmos_vsc_theme_flutter`
- `toColorScheme()` / `toThemeData()` из `VscColorTheme`
- Доп. виджеты: selection, checkbox, snackbar, dialog, FAB
- Хелпер `VscColor.toFlutterColor()`
