# Просмотр системных шрифтов

Flutter web пример для `atmos_local_fonts_flutter`.

English: [README.md](README.md).

Слева — список семейств, установленных в системе. Справа — текст выбранным
шрифтом, поле своего текста и готовые образцы: Lorem, панграммы, алфавит,
набор `Hamburgefonstiv`.

Список читается по кнопке: Local Font Access API требует жест пользователя.
Нужен Chrome или Edge.

## Запуск

```bash
cd packages/atmos_local_fonts_flutter/example
flutter pub get
flutter run -d chrome
```
