# Changelog

## 0.1.0

### EN

- Initial release: `loadLocalFontFiles` via `FontLoader`
- `FlutterLocalFonts` queries a `LocalFontSource` and registers faces
- `isLoading` while a query or load is in progress
- `isLoaded` / `isFamilyLoaded` after Flutter accepts the files
- `loadFamily` reads every installed face of the family, not one file

### RU

- Первый релиз: `loadLocalFontFiles` через `FontLoader`
- `FlutterLocalFonts` запрашивает `LocalFontSource` и регистрирует начертания
- `isLoading` на время запроса или загрузки
- `isLoaded` / `isFamilyLoaded` после того, как Flutter принял файлы
- `loadFamily` читает все установленные начертания семейства, не один файл
