# Changelog

## 0.1.1

### EN

- `readFileRange` reads a byte slice. The default loads the file and slices it

### RU

- `readFileRange` читает срез файла. По умолчанию файл загружается целиком и режется

## 0.1.0

### EN

- Initial release: VS Code–like `FileSystemProvider` surface
- `FileType`, `FileStat`, `FilePermission`, capability flags
- High-level `AtmosFileSystem` registry by URI scheme
- In-memory provider for tests and demos

### RU

- Первый релиз: провайдерный API в духе VS Code `FileSystemProvider`
- `FileType`, `FileStat`, `FilePermission`, флаги capabilities
- Высокоуровневый реестр `AtmosFileSystem` по scheme URI
- In-memory провайдер для тестов и демо
