# atmos_filesystem example (Flutter web)

Demo of the full stack on **Flutter web**:

- Directory picker → `AtmosFileSystem` (`fsa:///…`) list / read / write
- Open file picker (multi)
- Save file picker

Requires a Chromium-based browser (File System Access API).

## Run

```bash
cd packages/atmos_filesystem/example
flutter pub get
flutter run -d chrome
```

Use the buttons on the left; editor and log are on the right.
