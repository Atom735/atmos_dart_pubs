# atmos_vg_assets

Русский: [README_RU.md](README_RU.md).

Sample / demo GVG3 vector icons and pictures generated from SVG (local package, not published) — by Atom735.

## Install

```yaml
dependencies:
  atmos_vg_assets:
    path: packages/atmos_vg_assets
```

## Quick start

```dart
import 'package:atmos_vg_assets/atmos_vg_assets.dart';
import 'package:atmos_vg_assets/atmos_vg_icons.dart';

Widget icon() => AtmosIconsVgBase.ic_cross.getWidget();
```
