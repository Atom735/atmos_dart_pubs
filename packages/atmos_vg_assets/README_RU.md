# atmos_vg_assets

English: [README.md](README.md).

Демо-набор GVG3 иконок и картинок из SVG (локальный пакет, не публикуется) — by Atom735.

## Установка

```yaml
dependencies:
  atmos_vg_assets:
    path: packages/atmos_vg_assets
```

## Быстрый старт

```dart
import 'package:atmos_vg_assets/atmos_vg_assets.dart';
import 'package:atmos_vg_assets/atmos_vg_icons.dart';

Widget icon() => AtmosIconsVgBase.ic_cross.getWidget();
```
