# Планы

Черновик следующих пакетов. Текущий `atmos_vsc_codicon_flutter` сюда не входит:
он только поставляет готовый шрифт Codicon и кодпоинты.

## Пакеты для работы со шрифтами

Чистый Dart, без Flutter. Опора на `atmos_binary_buffer`.

- Чтение и запись TTF: `cmap`, `glyf`, `loca`, `head`, `hhea`, `hmtx`, `maxp`,
  `name`, `post`, `OS/2`.
- Контуры SVG (кубические Безье) → квадратичные контуры TrueType, переворот Y,
  сетка em.
- Направление обхода: внешний контур и дырки. Перекрывающиеся заливки и
  обводка, которую ещё надо превратить в контур, в первую версию не входят.

## Кодоген иконочного шрифта для Dart и Flutter

Отдельный CLI-пакет, не рантайм.

- Вход: папка SVG с заливкой, без градиента, клипа и обводки.
- Выход: `.ttf` и файл `static const IconData`.
- `atmos_vsc_codicon_flutter` этим генератором не заменяется. Его
  `tool/generate_codicons.dart` только копирует шрифт, собранный upstream, и
  таблицу id из сабмодуля `vscode-codicons`.

## Свой формат векторных иллюстраций

Отдельный пакет на набросках `gtm_vector_graphics_*` (GVG3: `VgContainer`,
пути, кисти, кадры). Для цветных иллюстраций, не для одноцветных иконок.

- Рендер закэшированным `ui.Picture`.
- Рантайм без зависимости от `vector_graphics_compiler`.
- Импорт SVG в контейнер остаётся шагом сборки, как сейчас в
  `gtm_vector_graphics_xml`.
